# Lesson02：Typst → Slidev 迁移调查与计划

调查日期：2026-11-11 · 状态：建议方案，待实施 · 基线：`a029a5f`

## 建议与范围

建议采用 **Slidev 静态课件 + 讲师本机 Bash 演示**，预算 **27–40 人时（约 3.5–5 个工作日，按 8 小时/日）**。学生打开课件就能先看命令、预测，再揭晓已录制的输出；讲师在本地专用入口可以对选定示例点「运行预设」，在同一页看到真实 Bash 的输出和退出状态。学生要改命令时，在自己的 Ubuntu Bash 中运行。Vim、补全、历史和 Ctrl+C 等操作继续用真实终端演示。

保留 90 分钟、六个教学模块和 E0–E8 的节奏，至少留足最后 8 分钟给综合挑战。现代化优先解决投影阅读、步骤揭示和输出对照：沿用 16:9，以 SAST 页脚和 Catppuccin Latte 作视觉起点，统一章节导航、中文和等宽字体、代码与输出的层次。首版用少量共享布局和一个演示组件，不做全站主题、权限/apt 新课、学生账号平台或 Lesson01 改造。

## 方案比较

| 方案 | 能做到什么 | 一次性工时 | 取舍 |
|---|---|---:|---|
| A：静态课件 + 实录回放 | 命令、逐步高亮、揭晓 stdout/stderr 和退出码；学生复制到自己的 Bash 验证 | 22–32 人时 | 最省维护，适合赶首课；网页按钮只揭晓录制结果 |
| **B：A + 讲师本机预设实跑（推荐）** | E2/E3/E6 在讲师版点击运行真实 Bash；学生版同一组示例可回放 | **27–40 人时** | 同时满足 Notebook 式讲解和真实执行，无公共运行服务；讲师需课前启动并检查环境 |
| C：学生在网页改写并执行 Bash | 浏览器内 Linux 虚拟机，或服务端提供独立的学生会话 | 在 B 上另加约 20–40 人时（浏览器 VM 可用性试点）或 45–80 人时（服务端小班试点） | 先验证冷启动、真实 Bash/GNU 兼容性、跨 cell 状态和设备覆盖；服务端还需隔离、限额、会话清理和运维。区间不含公开上线或长期维护 |

[Slidev 的 Monaco Runner](https://sli.dev/features/monaco-run) 原生执行 JavaScript/TypeScript；Bash 代码高亮、可编辑和可执行是三件事。[自定义 Runner](https://sli.dev/custom/config-code-runners) 提供接入点，执行环境仍需另建。[静态 SPA](https://sli.dev/guide/hosting) 能承载课件与回放，不能在普通浏览器里直接运行宿主 Bash。浏览器 VM 可参考 [v86 的官方演示](https://copy.sh/v86/)；能启动 Linux 不代表已满足本课 Ubuntu/Bash 环境和投影性能要求，暂不纳入首版。

## 演示设计

演示卡以「预测 → 揭晓 / 运行 → 解释」为顺序，命令保持可读、可复制；输出和退出码与命令分区。录制数据明确标记「示例输出」，实跑标记「本机 Bash」。危险示例只提供文字和模拟/录制结果，使用不可执行展示样式。PDF 使用同样的命令和静态结果，不能依赖按钮、滚动区或网络加载。

| 教案 | 网页/课堂形式 | 验收信号 |
|---|---|---|
| E0 环境检查 | 展示参考输出，学生在本机检查；用户名和路径示意脱敏 | 能辨认 Bash 所在系统，架构和用户名差异不判错 |
| E1 Shell、帮助、按键 | 短命令可回放；Tab、历史、Ctrl+C、man 用真实终端或离线录屏 | 能解释 Shell 和终端的分工 |
| E2 路径迷宫 | 可执行预设，逐步显示目录树和 `pwd`；学生跟做 | 每次从相同夹具开始，`cd` 的状态变化可见 |
| E3 cp/mv 预测 | 可执行预设，显示三种目标情况及运行前后的树 | 已有目录、生成文件、生成目录三种结果均可验证 |
| E4 rm 风险 | 只读讲解，危险原文不进入运行入口；示意绝对路径和未引用变量的后果 | 无可点击执行路径；临时工作目录不会被当成绝对路径的隔离边界 |
| E5 浏览和编辑 | `head` 可回放；less、`tail -f`、nano/Vim 用真实终端或短录屏 | 能退出分页器和编辑器、停止跟踪 |
| E6 管道与引号 | 可执行预设，逐步揭晓日志、过滤、计数和退出状态 | 五行固定输入，404 得 2、500 得 1；另验一个有 stderr/非零状态的示例 |
| E7–E8 挑战与总结 | 静态任务卡，学生在自己的 Bash 中独立完成，答案延后揭示 | 学生能解释管道、`>>` 与引号；可重复运行并观察追加 |

**脚本与状态。** 提议用 `demos/<id>/` 存放版本化脚本、夹具和录制输出，课件复用同一命令来源（可用 [Slidev snippet 导入](https://sli.dev/features/import-snippet)）。录制在 Ubuntu 24.04 Bash 中生成，归一化临时路径和可变环境字段，保留 stdout、stderr、退出码。E2/E3/E6 内部用同一次脚本调用或顺序重放前置步骤，让 `cd`、变量和文件具有真实语义；每次点击建立新的临时工作区，不在不同演示或浏览器刷新间保留状态。教学用的预期非零退出单独记录，不能被脚本的 fail-fast 设置吞掉。运行中的预设禁止重复触发，结果注明运行失败和回放退路。

**讲师运行入口。** 优先验证在讲师 Ubuntu 客户机内用同一个回环地址提供课件与执行入口；放映端进入该本地入口，避免把宿主浏览器能否连进 VMware 当成前提。入口只按固定 ID 执行仓库中的预设，浏览器提交的源码和参数不传给 Bash。普通用户运行，无 sudo，限定运行时间、输出和工作区，超时停止进程并回收工作区。避免跨来源调用，对运行请求验证本机来源，拒绝未知 ID。公开构建只包含回放和提示，既不请求该入口，也不依赖讲师服务。宿主机 Windows + WSL 仅作备选，单独验证其转发和环境差异。涉及交互终端或故意失败的高风险示例不注册为运行预设。

## 工时与实施顺序

按 1 位熟悉 Linux 和前端的实施者估算；包括本地交付和回归，不包含审批等待、学生平台、公开部署及补写完整的虚拟机安装手册。以下各项相加得到 B 的 27–40 人时；去掉第 5 项即 A 的 22–32 人时。

| 顺序 | 工时 | 要做什么 | 完成标志 |
|---|---:|---|---|
| 1. 基线与项目骨架 | 2–3 h | 保存 Typst 版对照；建立 Lesson02 独立项目，锁定 Node/npm/Slidev 版本和 lockfile，整理构建及忽略项 | 新目录可干净安装并启动；Lesson01 原构建不受影响 |
| 2. 代表页验证 | 3–5 h | 做封面/章节页、E3 表格或路径页、E6 演示卡三个代表页；跑一次静态 build、断网放映和 PDF 导出 | 课堂投影可读、字体不依赖 CDN、PDF 中可见静态结果 |
| 3. 迁移正文 | 6–8 h | 约 32 个标题单元，按每单元 10–15 分钟估算并取整；复用布局，改写密集表格、讲师备注和挑战页 | 六模块与 E0–E8 都有对应页，逐页对照原稿，保留授课顺序 |
| 4. 脚本、夹具与回放 | 4–6 h | 校对演示，录制并核对至少 E2/E3/E6，补充长日志及交互终端的离线替代素材 | 预设重跑结果一致，空输出、stderr 和非零状态显示清楚 |
| 5. 讲师本机实跑 | 5–8 h | 增加本机预设入口、运行状态与回放切换；先打通 E6，再扩 E2/E3；测试拒绝未知 ID、超时、重复点击及重置 | 客户机中点运行能看到真实结果；断开执行入口可立刻回放 |
| 6. 打包与回归 | 3–4 h | 做可重复的静态 build 和 Chromium PDF 导出；验证发布子路径（如采用）、资源路径、中文字体、投影和公共构建 | 干净检出可构建，发布版无本地运行请求，PDF 无裁切或空输出区域 |
| 7. 试讲、修订与切换 | 4–6 h | 实机走完 90 分钟时间轴（含一次断网/执行失败切换）；留出修订余量，写运行说明与回退入口 | 挑战留足 8 分钟，讲师知道如何启动、切换到回放和恢复旧入口 |

步骤 2 先用最小样板验证表现，步骤 5 再实现正式运行能力。若首课临近，可在步骤 2 的样板上用 **最多 2 人时（计入步骤 5）**提前验证讲师客户机里 E6 的执行链路；若没打通，首课交付 A 和真实终端，按计划继续补齐 B。C 只在确认学生需要在网页内编辑并执行命令后单独估算和立项。

## 发布、验收与回退

- Slidev 版本参考已核实的 [v53.1.0 发布](https://github.com/slidevjs/slidev/releases/tag/v53.1.0)及其 [Node 要求（≥22.22.0）](https://github.com/slidevjs/slidev/blob/v53.1.0/packages/slidev/package.json)；实施时锁版本、用 lockfile 复现，并在实际讲师机和构建机验证。文档也说明 [CLI PDF 导出需要 Playwright Chromium](https://sli.dev/guide/exporting)。本次未安装依赖、未运行 Slidev 构建或在客户机跑样板。
- 交付物：Lesson02 Slidev 源稿、预设脚本和回放、静态构建、PDF、讲师操作说明。若使用 GitHub Pages 等子路径托管，按实际发布 URL 设置 `base`，检查刷新、字体和素材；公开构建按需排除讲师备注。发布平台及启用时间不影响本地离线交付。
- 课堂验收：用真实投影或 1280×720 窗口检查字号、对比度、代码截断与键盘切页；断外网冷启动课件；点击实跑和回放比对 E2/E3/E6；关闭运行入口后仍能讲完 E0–E8；导出的 PDF 能独立看懂命令与结果。
- 旧 `slides.typ` 保留到新课件试讲通过，过渡期只在新稿更新，修正内容时不要长期双写。实施前生成可投影的 Typst PDF 基线；课堂故障时依次切到 Slidev 回放、预先导出的 PDF，必要时回到 Typst 基线。课后再决定是否归档旧稿。
