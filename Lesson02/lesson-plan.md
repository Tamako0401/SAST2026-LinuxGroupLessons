# Lesson02 授课计划：命令行核心用法

> 蓝本：《只学够用的 Linux：零基础最小入门教程》（<https://www.zouht.com/4399.html>，配套视频 BV13ctf6RECM）。
> 教程全文 3 万字以上、覆盖 100 余个命令。本课取第 1 章 1.2–1.7 的路径/文件/管道核心，再补 1.8 权限、1.9 软件包、1.10 SSH 与第 2 章的 systemd 入门，按 90 分钟重新组织。
> 面向对象：几乎零基础的大学新生（已完成 Lesson01，理论上已按《虚拟机安装手册》装好 Ubuntu；没装好的走结对/备用路线）。

## 一、授课范围

### 讲什么（本次课 7 个模块 + 1 个综合挑战）

| 模块 | 教程出处 | 核心内容 |
|---|---|---|
| ① Shell 与求助 | 1.2 | 提示符、命令结构、Tab 补全、↑ 历史、Ctrl+C、**--help 与 man（全课主线）** |
| ② 目录、文件与权限 | 1.3 + 1.8 | 单根 vs 盘符、绝对/相对路径、cd/ls/pwd/mkdir/touch、**ls -l 看权限 → chmod +x → sudo** |
| ③ 复制、移动、删除 | 1.4–1.5 | cp/mv 不看扩展名、rm 无回收站、**保命三招** |
| ④ 查看与编辑 | 1.6 | less/head/tail、nano 上手、vim 三模式 + :wq（会退出就行） |
| ⑤ 管道与特殊符号 | 1.7 | 通配符（只练 `*`）、重定向 `> >>`、管道 `|`、变量引号（压到安全点） |
| ⑥ 软件包管理 | 1.9 | apt update/search/install/remove、**apt vs pacman、编译 vs 二进制、固定 vs 滚动** |
| ⑦ 服务与远程 | ch2 + 1.10 | systemd/systemctl 启停、**PID 1 / UID 1 / /proc/1 辨析**、ssh 远程登录 |
| 综合挑战 | 1.2–1.7 | 一条管道统计 404，回收 Lesson01 伏笔 |

### 不讲什么（写进课件，让学生知道边界）

- **1.11 目录结构细节**：等大家用起来之后讲才有体感。
- **第 2、3 章其余**（tar、grep/sed 深入、链接、后台任务、journald 等）：后续课程。
- **权限深入**：只讲「看懂 `ls -l` + `chmod +x` + sudo」，不讲 umask、setuid、ACL、用户组管理。
- **软件包深入**：只讲 apt 四个动词 + 「什么是源」，编译安装/PPA/deb 打包一句话带过，不做。
- **systemd 深入**：只讲 systemctl 启停四个动词 + enable/disable，不写 unit 文件、不讲 journald。
- **ssh 深入**：只讲 `user@host` + `exit` + scp 一句，密钥认证/端口转发/tmux 不讲。
- **vim 详细操作**：只演示三模式和 `:wq`，明确说"会退出就行"，编辑器选择留给大家自己折腾。
- **find 高级用法**：只演示 `-name`，参数细节查 man。

### 取舍理由

- 弱化「命令背法」、强化「遇到问题会求助」：把 `--help`/`man` 立为全课主线，参数表、通配符细节能压就压。零基础最缺的不是命令清单，而是"不懂时问谁"。
- 权限提前讲、用报错开讲：`Permission denied` 是新手遇到最多的报错，讲明白它既解释了一半困惑，也是 apt（sudo）和 systemd（服务）的前置。
- apt/systemd/ssh 拉进课内但只讲「够用的一层」：它们是 Linux 真实世界的入口，光讲文件操作撑不满一节课，也接不住"这玩意到底能干嘛"的疑问。只讲到「会装 / 会启停 / 会连」，细节留课后自学。
- rm 安全仍单独立项：零基础阶段性价比最高的"救命知识"。
- 综合挑战不动：回收 Lesson01 的 `grep -x '404' status.log | wc -l` 伏笔，是「会用了」的验收点。

## 三、演示与互动环节清单

统一约定：所有危险操作（③ 的高危示例）只在 `mktemp -d` 建出的一次性目录里演示；apt/systemd/ssh 因需网络/root/第二台机器，一律讲师机现场演示、学生看，不进 NotebookDemo 运行按钮。互动沿用"**先预测，再执行，再解释**"三步式。

### E0 环境检查（0–5 min，互动）

- 全员在客户机终端执行 `whoami && pwd && cat /etc/os-release | head -n 2`。
- 举手分流：A 环境就绪 / B 没装好 → 结对 / C 其他路线（WSL2、机房机器）。
- 退路：完全没有环境的学生两人共用一台，本课所有动手环节两人一组即可完成。

### E1 这条命令是谁执行的？（5–12 min，演示 + 提问）

- 演示 `echo $SHELL`、`sleep 3`、`sleep 100` 后按 Ctrl+C（终端出现 `^C`）。
- 提问回收 Lesson01 伏笔："上一课说终端只负责交互、Shell 负责解释命令——现在 `sleep 100` 卡住终端，是谁在等？按 Ctrl+C 时是谁收到信号？"
- 演示 Tab 补全、↑ 历史、`ls --help`、`man ls`（man 里 `/pattern` 搜索、`n` 下一个、`q` 退出）。
- **立主线**：一句「遇到不懂的命令，先问它自己——`--help` / `man`」，之后每讲到一个新命令都回头指一下这条。
- 参数语法表压缩成一张图带过（短/长/带值/位置参数），不再逐个举例。

### E2 路径迷宫 + 权限现场（12–28 min，演示 + 全员跟做）

- 演示：`pwd` → `cd /` → `ls` → `cd ~` → `mkdir -p a/b/c` → `cd a/b/c` → 用 `../..` 跳回。
- 互动提问（先猜再验）："现在在 `~/a/b/c`，一条命令怎么回到 `~/a`？" `cd -` 演示"只记一次"，纠正"回退按钮"误解。
- `ls -l` 输出逐列解读，**权限这一列当场讲掉**（不再埋伏笔到下一课）：
  - `-rwxr-xr-x` 颜色分块：类型 1 位（`-` 文件 / `d` 目录 / `l` 链接）+ 三级各 3 位（user/group/other 的 rwx）。
  - 只讲「能看懂」+ `chmod +x` + 数字 755 一句话。
- **报错开讲权限**：`./run.sh` → `Permission denied` → `chmod +x run.sh` → 成功。before/after 两张屏，先让学生猜"为什么不让运行"。
- **sudo 一张图**：普通用户 → sudo → root 权限。一句话「借来的权力要密码」。
- 学生跟做：按讲义在家目录建 `sast-lab2` 目录树；给一个脚本 `chmod +x` 后运行。
- 退路：跟做进度不齐时，屏幕上常驻"目标目录结构图"，落后同学照图建完即可跟上。

### E3 先预测：cp 会把它放到哪？（28–33 min，互动）

- 给出三种场景让学生先写预测再执行（在实验目录内）：
  1. `cp file.txt dir`（dir 已存在）→ 放进 dir 里；
  2. `cp file.txt dir2`（dir2 不存在）→ 得到名为 dir2 的文件；
  3. `cp -r dir dir.txt` → 得到名为 dir.txt 的目录。
- 点破规则：cp/mv 不看扩展名。

### E4 rm 高危现场（33–38 min，演示，学生不跟做）

- 演示三类高危场景（全部在一次性目录里，`/data` 等路径换成实验目录内的假路径）：多打空格、相对/绝对路径一字之差、变量没加引号。
- 现场展示 `rm -rf /` 的特判报错（保证不真执行）。
- 保命三招：删目录先 `-i`/`-I`、敲绝对路径前停一秒、变量永远加双引号。
- 互动：一个学生上台，给一条"看起来正常"的 rm 命令，全班找茬。

### E5 退出 Vim 有多难？（38–46 min，演示 + 玩梗）

- 演示 `vim test.txt`：i → 输入 → ESC → `:wq`。提 Stack Overflow "how to exit Vim" 330 万浏览梗。
- nano 同样操作（Ctrl+S 保存、Ctrl+X 退出），立场：作业用 nano 够，vim 会退出就行。
- less/head/tail 演示：`less +/error`、`head -n 5`、`tail -f`（tail -f 不关，讲下一个知识点时回头一指"它还在跑"）。

### E6 一条命令的接力赛（46–56 min，演示 + 学生跟做）

- 逐层搭管道，每层先预测输出：
  1. `printf '%s\n' 200 404 200 500 404 > status.log`（复习 `>` 覆盖）
  2. `cat status.log | head -n 3`
  3. `grep -x '404' status.log | wc -l` —— 回收 Lesson01 伏笔。
  4. `&&` `||` 对比：`cd not-exist || echo "进不去"`、`mkdir demo && cd demo`。
- 通配符只练 `*`，`?` `[]` 一句话带过；变量/引号只留「变量永远加双引号」安全点。
- 学生跟做改写：把 404 换成 500。

### E7 综合挑战（56–66 min，全员动手）

任务卡（打在课件上，同时印在讲义末尾）：

1. 在 `~/sast-lab2` 里生成指定的五行 status.log。
2. **只用一条管道**统计其中 404 的行数。
3. 把结果追加（`>>`）到 `result.txt`，并解释为什么不能用 `>`。
4. 加分题：变量 `n=404`，用双引号写出 `grep -x "$n"` 版本，并解释单引号为什么不行。

验收方式：同桌互查 + 助教巡场，做出来的举手报数；最快的小组上台讲解自己的管道。

### E8 装一个东西（66–74 min，讲师演示，学生看）

- 心流图：源（仓库）→ apt → 你的系统。
- 演示 `apt update`（刷新菜单）→ `apt search` → `sudo apt install`（第一次真 sudo，呼应权限模块）→ `apt remove`。
- 讲清「跳过 update → `Unable to locate package`」这个第一坑。
- **发行版辨析（一句话带过，不做）**：
  - 包管理器按发行版家族分：Debian/Ubuntu 用 apt（.deb），Arch 用 pacman（.pkg.tar.zst），Fedora/RHEL 用 dnf/yum（.rpm）。命令不通用，别照着别的发行版抄。
  - 装软件两条路：二进制包（包管理器，快、推荐）vs 源码编译（`./configure && make && make install`，慢、要依赖、能定制）。
  - 更新模式：固定/大版本发布（Ubuntu LTS 两年一版，版本内 `apt upgrade` 不跨大版本，`do-release-upgrade` 才跨）vs 滚动更新（Arch，持续追最新）。

### E9 服务与远程（74–84 min，讲师演示，学生看）

- systemd = init 系统（PID 1，第一个进程，所有进程的祖先）；systemctl = 管理它的命令。
- 四动词 + 两词：`status / start / stop / restart` + `enable / disable`。**start/stop 管这一次，enable/disable 管开机自启**——这张两列表单独占一屏。
- **三个「1」辨析**（新手高频混淆）：
  - PID 1 = 第一个进程（systemd），不是用户。
  - UID 1 = 一个系统账号（传统上是 daemon），**不是 root**；root 是 UID 0。
  - /proc/1 = 进程 1 的虚拟目录（/proc 是内核按 PID 暴露的信息），`cat /proc/1/comm` 看到 systemd。
- ssh = 最流行的远程控制手段：`ssh user@host`，首次有 fingerprint 确认，`exit` 回来。重点看**提示符 hostname 变了没**。`scp` 一句带过。

### E10 总结与课后任务（84–90 min）

- 一句话串七个模块 + 念一遍 Unix 哲学："做一件事并做好，文本流是万能接口。"
- 课后任务（写进讲义）：
  1. 通读教程 1.2–1.7（本课只讲子集），并补读 1.8 权限、1.9 软件包、1.10 SSH（本课只讲了「够用的一层」）。
  2. nano 或 vim 二选一，写一份 200 字以内的"使用心得"或"翻车记录"。
  3. 在自己机器上 `sudo apt install cowsay`（或任一包），再 `ssh localhost` 连一次自己，记录提示符变化。
  4. 有余力：教程第 2 章任选一节（tar / grep 深入等），并把课堂挑战改成统计 500。

## 四、课件外的执行备忘

- 上课环境：讲师机 = VMware + Ubuntu 24.04（与课前手册一致）；终端字体调大（JetBrains Mono，与幻灯片代码块一致）。

- apt/systemd/ssh 演示需网络/权限/第二台机器，只讲师机做；断网预案：切换到提前录好的演示 GIF/截图（教程原文自带 30+ 张演示图，可直接引用并注明出处）。
- 演示翻车预案：讲师机出问题 → 用提前录好的演示；学生环境问题 → 一律结对，不现场修。
- 与现有材料的关系：`vm-install-guide.md` 转为课前任务发放；`lab.md` 的"先预测再执行"模式沿用为本课互动设计基础，本课动手环节以本计划的 E0–E7 为准，E8–E9 学生只看。
