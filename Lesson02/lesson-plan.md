# Lesson02 授课计划：命令行核心用法

> 蓝本：《只学够用的 Linux：零基础最小入门教程》（<https://www.zouht.com/4399.html>，配套视频 BV13ctf6RECM）。
> 教程全文 3 万字以上、覆盖 100 余个命令，本课只取其第 1 章 1.2–1.7 的核心子集，按 90 分钟重新组织，不生搬硬套。
> 面向对象：几乎零基础的大学新生（已完成 Lesson01，理论上已按《虚拟机安装手册》装好 Ubuntu；没装好的走结对/备用路线）。

---

## 一、授课范围

### 讲什么（本次课 6 个模块）

| 模块 | 教程出处 | 核心内容 |
|---|---|---|
| ① Shell 与命令 | 1.2 | 提示符、命令结构 `命令 [参数]...`、短/长参数、位置参数、Tab 补全、↑ 历史、Ctrl+C、--help 与 man |
| ② 目录、文件和路径 | 1.3 | `/` 与 `\`、单根 vs 盘符、大小写敏感、绝对/相对路径、`.` `..` `~`、cd / ls(ll) / pwd / cat / mkdir -p / touch / 运行可执行文件 |
| ③ 复制、移动、重命名 | 1.4 | cp/mv 的目标存在与否行为表、**不按扩展名判断类型**、父目录不存在报错 |
| ④ 删除 | 1.5 | rm 无回收站、-i/-I/-f/-r、rmdir、**三类高危误删场景** |
| ⑤ 查看和编辑 | 1.6 | less / head / tail（-f 一句带过）、nano 上手，vim 演示"如何退出"梗 |
| ⑥ 特殊符号 | 1.7 | 通配符 `* ? []`、重定向 `> >> 2>`、`; && ||`、管道 `|`、变量、单双引号区别、转义 |

### 不讲什么（写进课件，让学生知道边界）

- **1.8 用户和权限、1.9 软件包管理**：原计划第二课（VM 装机 + 换源）已把 apt 换源挪到课前任务；权限体系内容多，单独留给后续课。
- **1.10 ssh / 1.11 目录结构细节**：等大家用起来之后再讲才有体感。
- **第 2、3 章全部**（tar、grep/sed 深入、链接、后台任务、systemd 等）：后续课程。
- **vim 详细操作**：只演示三模式和 `:wq`，明确说"会退出就行"，编辑器选择留给大家自己折腾。
- **find 高级用法**：只演示 `-name`，参数细节查 man。

### 取舍理由

- 零基础新生第一次真正上手，**节奏优先于覆盖面**：宁可 6 个模块讲透、人人动手，也不把权限和 apt 塞进来导致后面互动全砍。
- 管道和重定向必须讲：Lesson01 结尾埋了 `grep -x '404' status.log | wc -l` 的伏笔（"Unix 哲学：文本流是万能接口"），本课回收这个伏笔，综合挑战就用它。
- rm 安全单独占一个模块并现场演示：这是零基础阶段性价比最高的"救命知识"。
- cp/mv 的"目标已存在行为"和"不看扩展名"是教程里整理得最好的规则表，直接搬，配"先预测再执行"。

## 三、演示与互动环节清单

统一约定：所有危险操作（模块④⑥的高危示例）只在 `mktemp -d` 建出的一次性目录里演示，讲义和课件里都要写明这一点；互动沿用"**先预测，再执行，再解释**"三步式（与现有 lab.md 一致）。

### E0 环境检查（0–5 min，互动）

- 全员在客户机终端执行 `whoami && pwd && cat /etc/os-release | head -n 2`。
- 举手分流：A 环境就绪 / B 没装好 → 结对 / C 其他路线（WSL2、机房机器）。
- 退路：完全没有环境的学生两人共用一台，本课所有动手环节两人一组即可完成。

### E1 这条命令是谁执行的？（5–15 min，演示 + 提问）

- 演示 `echo $SHELL`、`sleep 3`、`sleep 100` 后按 Ctrl+C（终端出现 `^C`）。
- 提问回收 Lesson01 伏笔："上一课我们说终端只负责交互、Shell 负责解释命令——现在 `sleep 100` 卡住终端，是谁在等？按 Ctrl+C 时是谁收到信号？"
- 演示 Tab 补全、↑ 历史、`ls --help`，顺势给出参数语法表。
- 学生跟做：用 Tab 补全敲出一条长命令，体验"不是背命令，是让终端帮你"。

### E2 路径迷宫（20–38 min，演示 + 全员跟做）

- 演示：`pwd` → `cd /` → `ls` → `cd ~` → `mkdir -p a/b/c` → `cd a/b/c` → 用 `../..` 跳回。
- 互动提问（先猜再验）："现在在 `~/a/b/c`，一条命令怎么回到 `~/a`？"`cd -` 演示"只记一次"的行为，纠正"回退按钮"的误解。
- `ll` 输出逐列解读（权限列先说"下一课细讲"，埋伏笔）。
- 学生跟做：按讲义在家目录建 `sast-lab2` 目录树。
- 退路：跟做进度不齐时，屏幕上常驻"目标目录结构图"，落后同学照图建完即可跟上。

### E3 先预测：cp 会把它放到哪？（38–47 min，互动）

- 给出三种场景让学生先写预测再执行（在实验目录内）：
  1. `cp file.txt dir`（dir 已存在）→ 放进 dir 里；
  2. `cp file.txt dir2`（dir2 不存在）→ 得到名为 dir2 的文件；
  3. `cp -r dir dir.txt` → 得到名为 dir.txt 的目录。
- 点破规则：**cp/mv 不看扩展名**。第 2、3 种情况是新手事故高发区。

### E4 rm 高危现场（47–55 min，演示，学生不跟做）

- 演示教程三类高危场景（全部在一次性目录里，`/data` 等路径换成实验目录内的假路径）：
  1. 多打一个空格：`rm -rf demo /demo2`（演示第一个参数被删）；
  2. 相对/绝对路径一字之差：`rm -rf data` vs `rm -rf /data`；
  3. 变量没加引号：`path="demo a demo b"; rm -rf $path` → 展开后删了多个路径。
- 现场展示 `rm -rf /` 的特判报错（在保证不会真执行的前提下讲解）。
- 给出保命三招：删目录先 `-i`/`-I`、敲绝对路径前停一秒、变量永远加双引号。
- 互动：让一个学生上台，给一条"看起来正常"的 rm 命令，全班找茬。

### E5 退出 Vim 有多难？（55–62 min，演示 + 玩梗）

- 演示 `vim test.txt`，按 i 输入，然后 ESC → `:wq`。提到 Stack Overflow "how to exit Vim" 330 万浏览量的梗。
- 再用 nano 做同样的编辑（Ctrl+S 保存、Ctrl+X 退出），明确立场：**本课作业用 nano 完全够**，vim 感兴趣课后自学。
- less/head/tail 演示：对课前准备好的长日志文件 `less +/error`、`head -n 5`、`tail -f`（tail -f 开着不关，讲下一个知识点时让它持续滚动，回头一指"它还在跑"）。
- 退路：vim/nano 环节整体可压缩到 3 分钟，只保 less/head/tail。

### E6 一条命令的接力赛（65–80 min，演示 + 学生跟做）

- 逐层搭管道，每层先预测输出：
  1. `printf '%s\n' 200 404 200 500 404 > status.log`（复习 `>` 会覆盖）
  2. `cat status.log | head -n 3` → "第 26~50 行"式需求：`cat access.log | head -n 50 | tail -n 25`
  3. `grep -x '404' status.log | wc -l` —— **回收 Lesson01 伏笔**："上一课这条命令是黑盒，现在每一节你们都认识了。"
  4. `&&` `||` 对比：`cd not-exist || echo "进不去"`、`mkdir demo && cd demo`。
- 学生跟做并改写：把 404 换成 500，预测结果。

### E7 综合挑战：一条管道统计日志（80–88 min，全员动手）

任务卡（打在课件上，同时印在讲义末尾）：

1. 在 `~/sast-lab2` 里生成指定的五行 status.log（命令在讲义里）。
2. **只用一条管道**统计其中 404 的行数。
3. 把结果追加（`>>`）到 `result.txt`，并解释为什么不能用 `>`。
4. 加分题：变量 `n=404`，用双引号写出 `grep -x "$n"` 版本，并解释单引号为什么不行。

验收方式：同桌互查 + 助教巡场，做出来的举手报数；最快的小组上台讲解自己的管道。

### E8 总结与课后任务（88–90 min）

- 一句话总结六个模块；再念一遍 Unix 哲学："做一件事并做好，文本流是万能接口。"
- 课后任务（写进讲义）：
  1. 通读教程 1.2–1.7 对应小节（本课只讲了子集，教程更细）；
  2. 自学教程 1.8 用户和权限 + 1.9 软件包管理（下一课的预习）；
  3. nano 或 vim 二选一，写一份 200 字以内的"使用心得"或"翻车记录"；
  4. 有余力：教程第 2 章任意一节 + 把综合挑战改成统计 500。

- 与现有材料的关系：`vm-install-guide.md` 转为课前任务发放；`lab.md` 的"先预测再执行"模式和提交模板沿用为本课互动设计基础，但本课的动手环节以本计划的 E0–E7 为准。
