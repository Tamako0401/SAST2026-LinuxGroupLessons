### 1. 什么是“轮子”？

你想造一辆自行车去上学，你需要做的是买车架、链条、变速器并组装起来，而不是自己去挖铁矿、炼钢，或者从砍树磨木头开始做圆形的橡胶车轮。那个圆形的、经过千万次验证的“轮子”，就是现存的基础设施。

在代码世界中，所有**已经被他人编写好、验证过、封装成模块并公开供他人调用的代码与工具**。
* **基础函数/算法级**：求平方根不需要手写牛顿迭代法（直接调 `math.sqrt`）；排序不需要每次手写快速排序。
* **通用库/工具级**：读写 Excel 文件、解析 JSON 数据、发送 HTTP 网络请求、生成二维码。
* **框架/平台级**：搭一个网站不需要从底层 Socket 通信写起（用 Spring Boot、Django、Express 或 Vue/React）。

### 2. 为什么不要重复造轮子？

个人时间极其有限，看不见的边界陷阱（你造的轮子大概率是方的）（漏洞百出、上线即崩溃），安全性问题

### 3. 去哪里找“轮子”？（课后再分享）

#### 官方语言包仓库（最标准、最直接的源头）

每门主流编程语言都有专门的官方或准官方“轮子超市”：

* **Python**：[PyPI](https://pypi.org/)（使用 `pip install`）
* **JavaScript / TypeScript**：[npm](https://www.npmjs.com/)（使用 `npm install`）
* **Java**：[Maven Central](https://central.sonatype.com/)（通过 Maven / Gradle 引入）
* **C / C++**：[vcpkg](https://vcpkg.io/)、[Conan](https://conan.io/)
* **Go**：[Go Packages](https://pkg.go.dev/)
* **Rust**：[crates.io](https://crates.io/)

#### 全球开源社区与索引平台

* **GitHub**：开源项目的聚集地。善用搜索语法（如 `stars:>1000 language:python topic:excel`）和 [Trending 趋势榜](https://github.com/trending)。
* **Awesome 列表**：GitHub 上的社区精选合集。直接搜索 `Awesome-Python`、`Awesome-Vue`、`Awesome-CS-Courses`，里面是全球开发者筛选出的各领域最佳轮子清单。
* **Libraries.io / npm trends**：用于查看开源库的依赖关系、历史更新活跃度及下载趋势对比。

#### 现代工作流：AI 辅助选型

教会新生向大语言模型提出高质量的咨询 Prompt：

> *“在 Python 3.12 中，目前最成熟、维护最活跃的用于处理高并发 HTTP 请求的库是哪个？请对比前两名的优缺点和适用场景。”*

    - 让答案沉淀下来，后来的人能搜到

    - 意思是：文档里写得清清楚楚，去读完再来
